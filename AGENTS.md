# Agent contract

This file governs agents working in this repository.

- Claims match evidence. A capability is "proven" only with a dated run record; everything else is "planned." Fabricated metrics, quotes, or citations are defects.
- Judgment gates stay human. An agent never answers a gate on a human's behalf; an unanswered gate is blocked work.
- Provenance travels with content: source, date, and run identity on any imported evidence.
- Generated outputs live under `board/out/` and stay untracked. Facts files under `board/facts/` are session records and say so.
- No personal paths, credentials, private repository content, or machine identifiers enter this repository.
- Lead with the claim in prose. Direct sentences, concrete nouns, evidence over adjectives.
